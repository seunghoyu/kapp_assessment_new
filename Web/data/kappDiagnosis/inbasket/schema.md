# 디지털 인바스켓 문항 스키마 (15_digital_inbasket_integration_plan 기준)

## 문항(Question) 필드

| 필드명 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| id | string | O | 고유 ID |
| title | string | O | 문항 제목 |
| category | string | O | 시뮬레이션 타입 (아래 16가지 중 하나) |
| sender | string | O | 발신자/출처 |
| date | string | O | 수신/작성일 표시용 |
| priority | string | O | 긴급 \| 보통 \| 낮음 |
| content | string | O | 본문/시나리오 설명 (rich text 가능) |
| attachments | string[] | - | 첨부 문서명 목록 |

- **category** → 직무 필터용 `jobCategory`는 앱에서 매핑 객체로 파생 (inbasketQuestions.json과 동일 매핑 사용).
- **응답 저장**: 요구사항상 저장하지 않음. 화면에서만 사용.

## 16가지 category 값

1. 이메일 관리  
2. 메신저 대응  
3. 보고서 작성  
4. 일정 관리  
5. 통합 업무  
6. 위기 관리  
7. 글로벌 협업  
8. 법무 검토  
9. 디지털 활용  
10. 인사 관리  
11. 재무 관리  
12. 고객 관리  
13. 윤리 경영  
14. 전략 기획  
15. 마케팅캠페인  
16. 생산관리  

## 직무 매핑 (12개, 목록 필터용)

- 이메일 관리, 메신저 대응 → 커뮤니케이션  
- 보고서 작성, 일정 관리, 전략 기획 → 경영/기획  
- 통합 업무, 글로벌 협업 → 프로젝트관리  
- 위기 관리 → 위기대응  
- 인사 관리 → 인사/조직  
- 재무 관리 → 재무/회계  
- 디지털 활용 → IT/디지털  
- 법무 검토, 윤리 경영 → 법무/컴플라이언스  
- 고객 관리 → 고객서비스  
- 마케팅캠페인 → 마케팅/영업  
- 생산관리 → 생산/운영
