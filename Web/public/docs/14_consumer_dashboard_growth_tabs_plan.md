# 마이 대시보드·나의 성장 탭 기획서 (수정안)

**기준**: kapp_origin 스크롤 형식 → new assessment ERP 대시보드형 전환  
**목표**: 스크롤 최소화, 탭으로 구분하여 한 화면에 가깝게 구성. 기능별 분산 완화, 직관적 그룹핑.

---

## 1. 배경 및 개선 방향

### 1.1 현황 (kapp_origin)

| 구분 | 현재 형태 | 이슈 |
|------|------------|------|
| **KAPP 대시보드** | 세로 스크롤 한 페이지에 다수 대형 섹션 | 스크롤이 길어 ERP 대시보드형과 맞지 않음 |
| **나의 성장** | 세로 스크롤 한 페이지에 3개 대형 섹션 | 동일 |

### 1.2 제외·삭제 항목 (origin 기준)

다음 영역은 **new에서 가져오지 않거나 내용을 삭제**한다.

| 항목 | 비고 |
|------|------|
| **DNA 영역** (나의 업무 DNA) | 전체 내용 삭제 |
| **스킬 성장 추이** | 내용 삭제 |
| **성장 트래킹** | 게이미피케이션, 배지·포인트·사내 랭킹 전체 삭제 |
| **뱃지** | 뱃지 컬렉션·배지 관련 UI 모두 제거 |

---

## 2. 마이 대시보드 (KAPP 대시보드)

### 2.1 기본 진입 화면: 내 역량

- 대시보드에 **들어갔을 때 기본으로 보이는 화면**은 **내 역량**이다.
- **탭은 2개만** 둔다: **시장·경쟁력**, **성장 로드맵**. (내 역량은 탭이 아니라 기본 뷰.)

### 2.2 내 역량 뷰 (기본 화면) 구성

**상단 고정 (항상 카드뷰 상단)**

- **AI 분석 인사이트**: 역량 진단 데이터 기반 맞춤형 조언. **내 역량 탭에서만** 노출되며, **항상 카드뷰 상단**에 위치한다.

**그 아래**

- **KAPP 4차원 역량 점수**: 레이더 차트, KAPP 진단 기반 점수, 직급 평균과 비교.

즉, 내 역량 화면 = **[AI 인사이트 카드(상단 고정)] + [4차원 역량 점수·레이더]**.

### 2.3 탭 2개 구성

| 탭명 | 포함 기능 | 비고 |
|------|-----------|------|
| **시장·경쟁력** | 시장 포지션 분석(현재 포지션, 경쟁력 분석, 성장 기회 카드 / 산업군 벤치마크 레이더(상위 10% vs 나) / 상위권 진입 추천 액션) + 시장 벤치마킹(동일 업계 대비 나의 위치) | 업계·시장 대비 위치를 한 탭에 통합 |
| **성장 로드맵** | 커리어 경로 시뮬레이터 + AI 생성 개인 개발 계획(IDP) | 스킬 갭·성장 경로·로드맵 통합. 스킬 성장 추이·성장 트래킹·뱃지는 포함하지 않음 |

### 2.4 마이 대시보드 요약

- **기본 노출**: 내 역량 (AI 인사이트 상단 + 4차원 역량 점수).
- **탭**: 시장·경쟁력 | 성장 로드맵.
- **삭제·미포함**: DNA, 스킬 성장 추이, 성장 트래킹(게이미피케이션/배지·포인트·랭킹), 모든 뱃지.

## 3. 나의 성장

### 3.1 상단 고정: 오늘의 1% 효율 챌린지

- **오늘의 1% 효율 챌린지**는 AI 인사이트와 동일하게 **항상 카드뷰 상단**에 위치한다.
- 매일 1분 실무 팁, 연속 학습 기록, 완료 수, 주간 목표, 지난 팁 다시보기 등은 이 상단 카드/블록 안에 구성한다.

### 3.2 그 아래: AI 커리어 멘토링

- **AI 커리어 멘토링**은 챌린지 카드 **바로 밑**에 배치한다.
- 다음 커리어 목표 선택, 1:1 AI 채팅, 현재 vs 목표 역량 갭 분석을 한 플로우로 노출한다.

### 3.3 탭: 인증서만

- **인증·이력** 대신 **인증서** 탭 하나만 둔다.
- **인증서 탭**에서 할 수 있는 것:
  - 역량 인증서 **확인(미리보기)**.
  - **PDF 다운로드** 버튼으로 인증서 다운로드.
  - (선택) 공유·링크 복사, 인증서 신뢰성 안내 등.
- **뱃지 컬렉션·배지 관련 내용은 모두 제거**한다.

### 3.4 나의 성장 요약

- **기본 화면**: 상단 = 오늘의 1% 효율 챌린지(고정) → 그 밑 = AI 커리어 멘토링.
- **탭**: **인증서** (해당 탭에서만 인증서 확인 + PDF 다운로드 등).
- **삭제·미포함**: 뱃지·배지 컬렉션, 기타 이력형 뱃지 UI.

---

## 4. 공통 적용 사항

- **탭 전환 시**: 스크롤 위치 초기화, 탭별로 독립된 “한 화면”처럼 동작하도록 구현.
- **반응형**: 작은 화면에서는 탭을 상단 가로 탭 또는 드롭다운으로 제공하고, 카드/그리드는 1열로 줄여도 가독성 유지.
- **접근성**: 탭에 `role="tablist"` 등 ARIA 적용, 키보드로 탭 이동 가능하게 하면 좋음.
- **데이터 연동**: 탭 구분과 무관하게, 진단 결과(localStorage/API)와 연동해 동일 데이터를 일관되게 사용.
