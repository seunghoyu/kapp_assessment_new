# 19 디지털 인바스켓 시뮬레이션 가이드

> 디지털 인바스켓에 **어떤 문항·상황이 있는지**, **어떻게 푸는지**, **어떻게 풀면 높게·낮게 평가될 수 있는지** 정리한 문서입니다.  
> 기획·운영·학습자·채점 기준 설계 시 참고용입니다.

---

## 1. 디지털 인바스켓이란

- **실전 업무 의사결정 시뮬레이터**입니다.
- 이메일, 메신저, 보고서, 일정, 위기, 법무, 재무, 인사, 고객, 윤리, 전략, 마케팅, 생산 등 **다양한 업무 상황**이 인바스켓(받은 편지함)에 들어온다고 가정하고, 학습자가 **우선순위 판단·의사결정·조치 선택**을 하는 형태입니다.
- 문항은 **16가지 시뮬레이션 타입(카테고리)** 으로 구분되며, 타입당 여러 문항이 있어 **총 48개**까지 구성할 수 있습니다. (현재 데이터: `data/kappDiagnosis/inbasket/inbasketQuestions.json`)

## 3. 시뮬레이션별 푸는 방법 (UI·선택지 요약)

진단 화면에서 문항을 선택하고 **「진행하기」** 를 누르면, 해당 문항의 **카테고리**에 맞는 시뮬레이션 화면이 열립니다. 각 타입별로 **어떤 선택을 하는지** 요약합니다.

| 카테고리 | 푸는 방법 (학습자가 하는 일) |
|----------|-----------------------------|
| **이메일 관리** | 받은 편지함에서 메일을 선택 → 각 메일마다 **처리 액션**(회신/전달/보관 등)·**우선순위** 선택. 문항 메일 + 추가 4통으로 5통 구성. |
| **메신저 대응** | 채널 #긴급-요청의 메시지별로 **즉시처리/위임/대기/정보수집** 중 선택, 필요 시 **우선순위** 지정. |
| **보고서 작성** | 6개 부서(영업·마케팅·개발·인사·재무·고객지원) 중 **미제출/부분제출** 부서에 대해 **긴급도**(높음·보통·낮음)·**조치**(긴급 독촉/기존자료 대체/제외/간략요약)·메모 입력. 보고서 **개요·부서별 분석·결론** 텍스트 작성. |
| **일정 관리** | 14시에 겹친 3개 회의(신제품 런칭, 투자자 미팅, 전사 간담회) 각각에 **직접 참석/대리 참석/시간 변경/불참** 중 선택. |
| **통합 업무** | 이메일·전화·SNS·메신저 탭별로 문의 목록 확인 후, 문의마다 **즉시처리/부서이관/보류/에스컬레이션** 선택. |
| **위기 관리** | **대응 전략**(선제 보도/언론 협상/침묵/자진 리콜)·**위기대응팀 구성**(CEO·홍보·법무·품질·고객서비스·외부 전문가 복수 선택)·**고객 커뮤니케이션**(이메일 SMS/홈페이지 공지/개별 연락/보도 후 보고)·**긴급 예산**(4개 항목 체크, 총액 상한 2억 5,800만원) 결정. |
| **글로벌 협업** | **회의 시간 조율**(야근/새벽/녹화 공유/분할 회의/비동기 문서 중 선택)·**커뮤니케이션 프로토콜**(Slack/이메일/화상/문서 공유) 선택. 문서 버전 관리 안내 확인. |
| **법무 검토** | 6개 조항(계약 금액·위약금·품질보증·지적재산권·비밀유지·일방 해지)별 **위험도** 확인 후, **수정요청/협상/수용/거절** 중 선택. |
| **디지털 활용** | 4종 도구(ChatGPT Plus, Notion AI, Midjourney, GitHub Copilot)별 **즉시 도입/추후 검토/불필요** 선택 + **우선순위 1~4** 지정. |
| **인사 관리** | **프로세스 정립**(SOP 정립/워크플로 개선/정기 협의체/조정자 지정)·**팀빌딩**(워크숍/합동 프로젝트/협업 교육/순환 근무)·**개별 면담**(잔류 제안/타부서 이동/퇴사 수용/조정) 중 각 1개 선택. |
| **재무 관리** | 마케팅·연구개발·영업·생산 4개 부서별 **전액 승인/일부 승인/거부/차기 분기** 선택 + 필요 시 **배분액(원)** 입력. |
| **고객 관리** | **즉각 대응**(CEO 방문/대응팀 파견/개선안 제시/긴급 보상)·**가격 협상**(수용/부분 수용/대체안/거부)·**품질 보증**(5년/3년/프리미엄/품질 투자)·**관계 강화**(전담팀/정기 미팅/파트너십) 각 1개 선택. |
| **윤리 경영** | **초기 대응**(즉시 조사/윤리위원회/외부 감사/내부 사전조사)·**대상자 조치**(직위 해제/타부서 배치/현 업무 유지/자택 대기)·**조사 범위**(거래 내역·협력업체·금융·이메일 로그 복수 선택)·**공개·보고**(즉시 공개/이사회 후/조사 완료 후/최소 공개) 선택. |
| **전략 기획** | M&A 건에 대해 **재무적 타당성·전략적 적합성·실사 리스크** 검토 후, **통합(PMI) 전략**(완전/단계적/독립/혼합) 선택 + 통합 예산 입력, **최종 의사결정**(승인/재협상/실사 후 재검토/포기) 선택. |
| **마케팅캠페인** | SNS 인플루언서·온라인 광고·오프라인 이벤트·이메일 마케팅 4개 캠페인별 **예산 집행·성과** 확인 후 **계속/확대/축소/중단** 선택, 필요 시 **조정 예산(원)** 입력. 우측 ROI 패널 참고. |
| **생산관리** | 4개 라인(A·B·C·D) 중 B(긴급 중단)·C(주의)·D(시험)에 대해 **라인별 조치** 선택: B는 원자재 교체/라인 전환/외주 생산/납기 연장, C는 유지보수/조기 설비 교체/생산 축소, D는 양산 진행/테스트 연장/개선 후 진행. |

## 4. 높게 나오는 경우·낮게 나오는 경우 (평가 관점)

> **참고:** 현재 학습자 LMS 앱에서는 시뮬레이션 선택지에 대한 **자동 채점·점수 산출**이 구현되어 있지 않습니다. 아래는 **역량 관점에서의 권장 해석·평가 기준**으로, 추후 채점 로직을 넣을 때나 학습자가 자기 점검할 때 참고할 수 있습니다.

### 4.1 공통 원칙

- **우선순위 반영:** 긴급/중요 건을 먼저 처리하고, 보통·낮음은 순서대로 반영하면 높게 평가될 가능성이 큽니다.
- **일관성·적절성:** 상황(제보, 위기, VIP, 계약 리스크 등)에 맞는 조치를 고르는 것이 좋습니다. 과도한 조치(즉시 직위 해제·과다 예산)나 지나치게 소극적 조치(침묵 유지·전부 거부)는 낮게 볼 수 있습니다.
- **완결성:** 해당 시뮬레이션에서 요구하는 **모든 단계**(전략·팀·커뮤니케이션·예산 등)를 빠짐없이 결정하면 높게, 일부만 하면 낮게 볼 수 있습니다.

### 4.2 타입별 관점 (요지)

| 카테고리 | 높게 나올 수 있는 선택 (요지) | 낮게 나올 수 있는 선택 (요지) |
|----------|-------------------------------|-------------------------------|
| 이메일 관리 | 긴급 메일 우선 처리·명확한 액션·회신/위임 구분 | 모든 메일 동일 대우·우선순위 무시 |
| 메신저 대응 | 긴급 메시지 즉시처리·위임 시 적절한 수신자 구분 | 긴급 건 대기·정보수집만 반복 |
| 보고서 작성 | 미제출 부서에 우선순위·조치 명확히·완성도 있는 초안 | 미제출 부서 방치·요약·결론 없음 |
| 일정 관리 | 중요 회의 직접 참석·투자자/신제품 우선·낮은 우선순위는 대리/불참 | 전부 불참·중요 건 시간 변경만 |
| 통합 업무 | VIP·긴급 문의 즉시처리/에스컬레이션·채널별 우선순위 | 모든 문의 보류·일괄 이관 |
| 위기 관리 | 선제적·투명한 대응(보도·고객 공지)·팀 구성·예산 적정 | 침묵 유지·팀·공지·예산 미결정 |
| 글로벌 협업 | 타임존 고려(녹화/분할/비동기)·문서·커뮤니케이션 프로토콜 명확 | 한쪽 시간만 강요·프로토콜 없음 |
| 법무 검토 | 고위험 조항 수정요청·협상·중위험 검토·저위험 수용 | 전부 수용 또는 전부 거절 |
| 디지털 활용 | ROI·비용 대비 도입·우선순위 명확(핵심 업무 연관 도구 우선) | 전부 불필요/전부 즉시 도입 |
| 인사 관리 | 갈등 당사자·퇴사 예정자 고려한 프로세스·팀빌딩·면담 조합 | 일방적 직위 해제·조정 없음 |
| 재무 관리 | 부서별 사유 검토·전액/일부/거부/차기 분기 구분·총액 일관 | 전부 거부 또는 전액 승인만 |
| 고객 관리 | VIP 대응 수준(CEO 방문·전담팀)·가격·품질·관계 조합 | 소극적 보상·관계 강화 없음 |
| 윤리 경영 | 초기 대응(내부/윤리위원회)·조사 범위 적정·공개 시점 합리 | 즉시 직위 해제·조사 없이 공개 |
| 전략 기획 | 실사·통합 전략·예산 근거·최종 승인/재협상/포기 구분 | 감정적 승인/포기·근거 없음 |
| 마케팅캠페인 | 성과 좋은 캠페인 확대·나쁜 캠페인 축소/중단·ROI 반영 | 전부 계속 또는 전부 중단 |
| 생산관리 | 긴급 라인(원자재/라인 전환/외주) 신속 결정·납기·재고 반영 | 조치 미선택·일괄 납기 연장 |

### 4.3 채점 구현 시 참고

- 각 시뮬레이션의 **선택지 값**(예: `수정요청`, `즉시처리`, `전액 승인`)을 서버 또는 클라이언트에서 **정답/권장 패턴**과 비교하는 방식으로 점수화할 수 있습니다.
- **문항별·시나리오별**로 “권장 조합”을 JSON 또는 DB에 두고, 학습자 선택과 매칭하여 점수·피드백을 낼 수 있습니다.
- 상세 채점 규칙은 **역량 정의**(의사결정, 우선순위, 리스크 관리, 커뮤니케이션 등)와 연계해 16가지 타입별로 세부 기준을 두는 것을 권장합니다.
