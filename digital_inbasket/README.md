# 디지털 인바스켓 시스템 (Digital In-Basket System)

실전 비즈니스 상황을 시뮬레이션하여 의사결정 능력을 평가하고 훈련할 수 있는 인터랙티브 웹 기반 인바스켓(In-Basket) 시스템입니다.

## 프로젝트 개요

인바스켓(In-Basket) 평가는 관리자나 의사결정자가 실제 업무 현장에서 마주할 수 있는 다양한 상황(이메일, 보고서, 메모 등)을 제시하고, 제한된 시간 내에 우선순위를 정하고 적절한 조치를 취하는 능력을 평가하는 도구입니다.

본 시스템은 이러한 인바스켓 평가를 **게이미피케이션** 요소와 함께 디지털 환경에서 구현하여, 학습자가 **실제 업무 환경**에서처럼 체계적으로 의사결정 역량을 훈련할 수 있도록 지원합니다.

## 주요 특징 🌟

### ✨ 게이미피케이션 & 실감나는 업무 환경
- **16가지 완전 구현된 시뮬레이션** - 실제 Outlook, Slack, Google Calendar, MS Office, CRM, 법무 시스템 등 재현
- 타입별 특화된 몰입형 인터페이스
- 즉각적인 시각적 피드백 (아이콘 변화, 색상 변화, 진행률 표시)
- 10분 타이머와 실시간 진행률 추적
- 실무 의사결정 프로세스 완벽 재현

### 🎯 다양한 직무 시나리오
- 12가지 직무 카테고리로 체계적 분류
- **16가지 실전 비즈니스 시나리오 타입** (모두 구현 완료)
- 22개 이상의 실무 문항 (긴급 12개, 보통 7개, 낮음 3개)
- 각 시나리오별 맞춤형 의사결정 인터페이스

## ✅ 현재 완료된 모든 기능

### 🎨 메인 화면
- 그라데이션 디자인과 애니메이션 효과
- 알약(Pill) 형태의 컴팩트한 직무 필터 버튼 (12개 카테고리)
- 카드 기반 반응형 그리드 레이아웃 (모바일 1열, 태블릿 2열, 데스크톱 3열)
- Floating 애니메이션과 3D 호버 효과
- 모달 기반 문항 상세보기

### 💼 직무별 문항 분류 (12가지)
1. **전체** - 모든 문항
2. **경영/기획** - 이메일, 보고서, 일정, 전략
3. **커뮤니케이션** - 메신저
4. **고객서비스** - 고객 관리
5. **프로젝트관리** - 통합 업무, 글로벌 협업
6. **위기대응** - 위기 관리
7. **인사/조직** - 인사 관리
8. **재무/회계** - 재무 관리
9. **IT/디지털** - 디지털 활용
10. **법무/컴플라이언스** - 법무 검토, 윤리 경영
11. **마케팅/영업** - 마케팅 캠페인
12. **생산/운영** - 생산 라인 관리

## 🎮 16가지 실전 시뮬레이션 (모두 구현 완료!)

### 1. ✉️ 이메일 관리 (Outlook 스타일)
- 좌측 폴더 및 이메일 리스트 (읽지 않은 메일 파란 점)
- 우측 이메일 상세 뷰어
- 답장/전달/보관/삭제 버튼
- 🔴긴급 / 🟠중요 / 🔵보통 우선순위 아이콘
- 완료 시 녹색 체크 표시

### 2. 💬 메신저 대응 (Slack/Teams 스타일)
- 보라색 채널 사이드바
- 메시지 스트림
- ⚡즉시 / 👤위임 / ⏰대기 / 🔍정보수집 처리 옵션
- 1~4순위 우선순위 선택
- 긴급 메시지 빨간 배경 강조

### 3. 📊 보고서 작성 (MS Office 스타일)
- Word 스타일 리본 메뉴 (폰트, B/I/U, 차트/표/이미지)
- 좌측: 부서별 데이터 수집 패널 (6개 부서, 제출 상태, 우선순위, 조치 선택)
- 중앙: A4 보고서 편집 영역
- 우측: 디자인 도구 (테마, 레이아웃, 요소 추가)

### 4. 📅 일정 관리 (Google Calendar 스타일)
- 시간대별 타임라인 그리드 (9시~20시)
- 14시 3개 회의 충돌 시각화 (빨간 배경 애니메이션)
- 회의 카드: 참석자, 자료, 장소, 시간
- 직접 참석 / 대리 참석 / 시간 변경 / 불참 결정

### 5. 🔄 통합 업무 (멀티채널 대시보드)
- 4개 채널 탭 (이메일/전화/SNS/메신저)
- 채널별 문의 리스트 및 긴급 배지
- 즉시처리 / 부서이관 / 보류 / 에스컬레이션 옵션
- 우측 패널: 채널별 처리 현황 통계

### 6. 🚨 위기 관리 (Crisis Control Room)
- 빨간 배경 전체 화면, 6시간 카운트다운
- 좌측 상황판: 실시간 상태 (자체 검사 OK, 외부 재검토, 법무 대응, 고객센터 문의 폭주)
- 우측 4단계 의사결정 체크리스트:
  1. 즉각 대응 전략 (보도자료/협상/침묵/리콜)
  2. 위기대응팀 구성 (6명 멀티 선택)
  3. 고객 커뮤니케이션 방법
  4. 긴급 예산 승인 (실시간 합계 최대 2억 5,800만원)
- 단계 완료 시 노란색→녹색 변화

### 7. 🌍 글로벌 협업 (World Map Timezone Manager) - NEW!

### Responses (응답 테이블)
| 필드명 | 타입 | 설명 |
|--------|------|------|
| id | text | 고유 ID |
| question_id | text | 문항 ID |
| action_taken | text | 조치 사항 |
| priority_assigned | text | 부여한 우선순위 |
| delegate_to | text | 위임 대상 |
| notes | rich_text | 메모 및 의견 |
| completed | bool | 완료 여부 |
| response_time | datetime | 응답 시간 (밀리초) |

## 주요 기능 URI

### 메인 페이지
- **URI**: `/` 또는 `/index.html`
- **설명**: 인바스켓 문항 목록 및 필터링 인터페이스
- **기능**:
  - 12가지 직무 카테고리 필터
  - 22+ 문항 카드 그리드 표시
  - 모달 상세보기
  - 시뮬레이션 시작 버튼

### 시뮬레이션 페이지
- **URI**: `/simulation.html?id={question_id}`
- **설명**: 실전 시뮬레이션 모드 실행
- **기능**: 
  - 10분 타이머
  - 진행률 표시
  - 16가지 타입별 맞춤 UI
  - 실시간 응답 저장
  - 게이미피케이션 요소

### API Endpoints (RESTful Table API)

#### 문항 조회
- **GET** `tables/questions?limit=100`
- **설명**: 모든 문항 목록 조회

#### 단일 문항 조회
- **GET** `tables/questions/{question_id}`
- **설명**: 특정 문항 상세 정보 조회

#### 응답 저장
- **POST** `tables/responses`
- **설명**: 새로운 응답 저장

#### 응답 수정
- **PUT** `tables/responses/{response_id}`
- **설명**: 기존 응답 수정
