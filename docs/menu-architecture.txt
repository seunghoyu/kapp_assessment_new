================================================================================
3. Depth 기준 요약
================================================================================

Depth 1 : 최상위 서비스 메뉴 (홈, 로그인, 관리자 로그인, 대시보드)
Depth 2 : 주요 기능 메뉴 (앱 내 진단/대시보드/교육/성장, 관리자 대시보드 하위)
Depth 3 : (현재 프로젝트에서 별도 URL로 구분된 세부 페이지 없음)
Depth 4 : (진단 내 단계는 단일 URL /app/diagnosis 내 상태로 처리됨)


================================================================================
4. 참고: 진단 단계 (동일 URL /app/diagnosis)
================================================================================

다음 단계는 별도 URL 없이 /app/diagnosis 한 페이지 내에서 단계 전환으로 동작함.

- step 0 : 시작
- step 1 : 정보 입력 (산업·직무, 직급, 연차 등)
- step 2 : 지식 문항
- step 3 : 적용 문항
- step 4 : 성과 문항
- step 5 : 디지털 인바스켓 (E-tray)
- step 6 : 결과


================================================================================
5. 분석 근거
================================================================================

- 라우트 상수: lib/routes.ts (ROUTES)

- 관리자 사이드바: components/layout/Sidebar.tsx
- 앱 레이아웃: app/app/layout.tsx (ConsumerSidebar 사용)
- 대시보드 레이아웃: app/dashboard/layout.tsx (Sidebar 사용)
- 페이지: app/**/page.tsx (Next.js App Router)
