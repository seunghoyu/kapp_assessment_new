# KAPP 서비스 구조도 (수정 반영본) — React Flow 초안용

※ **본문**: 기획자도 이해할 수 있도록 기능·화면 중심 서술.
※ **하위 [개발]**: 개발자용 상세 — 파일 경로, 상태/키 이름, 데이터 구조, 컴포넌트·props 보완.
※ JSON 샘플이 있는 항목은 구조도에서는 **하나의 노드**로 표현 (상세는 노드 클릭/툴팁 등으로 분리 전달).
※ React Flow로 구현 시 Cursor에 **단계별 프롬프트**로 나눠 전달할 것 (본 문서 하단 참고).

================================================================================
트리 1: 학습자 LMS (Root → / → /login → /app)
================================================================================

Root (진입점)
 │
 ├─ / (홈, Landing)
 │    ├─ [버튼] KAPP 진단 시작하기 → /login
 │    ├─ [버튼] 서비스 둘러보기
 │    ├─ [링크] KAPP 진단 시작하기 (Hero)
 │    ├─ [링크] 체험하기 → /login
 │    ├─ [링크] 무료로 진단 시작하기 → /login
 │    ├─ [링크] 도입 문의 (1:1 상담) → /admin
 │    └─ Footer: KAPP 진단, 대시보드 → /login, /app
 │
 ├─ /login (학습자 로그인/회원가입)
 │    ├─ [입력] 이메일, 비밀번호
 │    ├─ [체크박스] 전체 동의 / 필수 개인정보·이메일·전화 마케팅
 │    ├─ [버튼] 내용 보기 → 모달 (약관 전문)
 │    ├─ [버튼] 로그인 | 회원가입 → localStorage 저장 후 /app 이동
 │    └─ [링크] 관리자 페이지로 이동 → /admin
 │
 ├─ /admin (관리자 로그인)
 │    ├─ [입력] 이메일, 비밀번호
 │    ├─ [버튼] 로그인 → /dashboard
 │    └─ [링크] 홈으로 돌아가기 → /
 │
 └─ /app (학습자 LMS: ConsumerSidebar + 본문)
      │
      ├─ [사이드바] ConsumerSidebar
      │    ├─ [로고] 클릭 → /app
      │    ├─ [버튼] 접기/펼치기 (isCollapsed)
      │    ├─ [메뉴] KAPP 진단 → /app/diagnosis
      │    ├─ [메뉴] 마이 대시보드 → /app/dashboard
      │    └─ [메뉴] 나의 성장 → /app/growth
      │
      ├─ /app (앱 홈)
      │    └─ [버튼] KAPP 진단 시작하기 → /app/diagnosis
      │
      ├─ /app/diagnosis (KAPP 지능형 역량 진단)
      │    ├─ [상단 헤더] 고정 (sticky)
      │    │    ├─ 제목 "KAPP 지능형 역량 진단"
      │    │    └─ 부제 Knowledge·Application·Performance·Productivity
      │    ├─ [단계 버튼] 시작·정보·지식·적용·성과·인바스켓·결과 (STEPS, step 0~6)
      │    ├─ step 0 (시작)
      │    │    └─ [버튼] 진단 시작하기 → step 1
      │    ├─ step 1 (정보 입력)
      │    │    ├─ [데이터 노드] userInfoOptions — 산업·직무, 직급, 연차, 기업규모, 진단목표 옵션
      │    │    │    [개발] userInfoOptions.json 경로. 키: industryJobData, positionLevels, experienceYears, companySizes, diagnosticGoals. industryJobData는 산업명 키 → { icon, jobs[] }.
      │    │    │    [샘플] industryJobData
      │    │    │      "IT": { "icon": "💻", "jobs": ["개발자(Backend)", "개발자(Frontend)", "데이터 엔지니어", "정보보안", "DevOps", "UI/UX 디자이너", "QA/테스터", "프로젝트 매니저"] }
      │    │    │      "금융": { "icon": "🏦", "jobs": ["카드사업부 마케터", "여신심사역", "리스크 관리", "IB 애널리스트", "자산관리(PB)", …] }
      │    │    │      "교육", "의료", "제조", "유통/리테일", "마케팅/광고", "호텔/관광", "법률/회계", "기타" (동일 구조)
      │    │    │    [샘플] positionLevels[0] { "value": "인턴", "label": "인턴" }
      │    │    │    [샘플] experienceYears[0] { "value": "1년 미만", "label": "1년 미만 (신입)" }
      │    │    │    [샘플] companySizes[0] { "value": "대기업", "label": "대기업 (1000명 이상)", "icon": "🏢" }
      │    │    │    [샘플] diagnosticGoals[0] { "value": "승진", "label": "승진 준비" }
      │    │    ├─ [산업군 선택 동작]
      │    │    │    ├─ [버튼] "산업군 선택" 클릭 → 산업 선택 모달 열림
      │    │    │    │    [개발] industrySelectModalOpen=true. IndustrySelectModal 렌더.
      │    │    │    ├─ [데이터] 산업 대분류 목록 → 모달에 전달해 그리드 표시
      │    │    │    │    [개발] data/Industry/industry_tree.json. IndustryNode[] (code, name, children 재귀). 모달 props: majors=industryTreeData.
      │    │    │    ├─ [모달] 산업군 선택 모달 — 대분류 그리드, 상세보기, 선택/닫기
      │    │    │    │    [개발] IndustrySelectModal. state: selectedMajorInModal(IndustryNode). 대분류 그리드 majors.map → 클릭 시 setSelectedMajorInModal(major). [상세보기] → setClassificationMajor(selectedMajorInModal), IndustryClassificationModal open. [선택] → onSelect(major) → 부모 handleIndustrySelect: setSelectedMajor(major), setForm(industry: major.name, job: ""), 모달 닫기. [닫기] onClose.
      │    │    │    └─ [모달] 산업 분류 체계 상세 — 선택한 대분류의 중·소·세·세세 테이블
      │    │    │          [개발] IndustryClassificationModal. props: majorName, middleNodes(=선택 대분류.children, 중분류 배열). 4열 테이블: 중|소|세|세세분류(children 단계별). 닫기: 대분류 선택 / X.
      │    │    ├─ [산업군과 함께 조회하는 데이터]
      │    │    │    ├─ 산업 대분류·분류체계 → 모달 표시용
      │    │    │    │    [개발] industry_tree.json. IndustryNode[] 샘플: { "code": "A", "name": "농업, 임업 및 어업", "children": [ { "code": "01", "name": "농업", "children": [ … ] }, … ] }
      │    │    │    └─ 산업별 세부 직무 목록 → 직무 select 옵션
      │    │    │          [개발] userInfoOptions.industryJobData[form.industry] → jobList. form.industry 선택 후 직무 <select> 옵션에 사용.
      │    │    ├─ [입력] step 1 폼 필드 — 선택지 전체
      │    │    │
      │    │    │    [입력·텍스트]
      │    │    │    이름, 이메일, 회사명 — 자유 입력
      │    │    │
      │    │    │    [산업군]
      │    │    │    모달 선택 — industry_tree.json 최상위 대분류 21개 (예: 농업·임업 및 어업, 광업, 제조업, …)
      │    │    │
      │    │    │    [세부 직무] 드롭다운(산업군 의존) — industryJobData[산업].jobs
      │    │    │      IT: 개발자(Backend), 개발자(Frontend), 데이터 엔지니어, 정보보안, DevOps, UI/UX 디자이너, QA/테스터, 프로젝트 매니저
      │    │    │      금융: 카드사업부 마케터, 여신심사역, 리스크 관리, IB 애널리스트, 자산관리(PB), 핀테크 기획자, 준법감시, 금융상품 개발
      │    │    │      교육: 강사/교수, 교육 콘텐츠 기획자, 교육 컨설턴트, LMS 관리자, 커리큘럼 디자이너, 에듀테크 PM
      │    │    │      의료: 의사, 간호사, 의료 행정, 의료 IT, 임상시험 코디네이터, 제약 마케터, 병원 경영
      │    │    │      제조: 생산 관리, 품질 관리, SCM 담당자, 공정 엔지니어, R&D 연구원, 구매/자재
      │    │    │      유통/리테일: MD, 바이어, 매장 관리자, 물류 담당자, E-커머스 운영, 유통 기획
      │    │    │      마케팅/광고: 디지털 마케터, 퍼포먼스 마케터, 브랜드 매니저, 콘텐츠 마케터, 광고 AE, 소셜미디어 매니저
      │    │    │      호텔/관광: 호텔리어, 여행 상품 기획자, 관광 컨설턴트, F&B 매니저, 이벤트 플래너
      │    │    │      법률/회계: 변호사, 노무사, 세무사, 회계사, 법무팀, 재무 분석가
      │    │    │      기타: 인사/HR, 총무, 경영 기획, 영업, 고객 서비스, 일반 관리
      │    │    │
      │    │    │    [직급] 드롭다운 (8개)
      │    │    │      인턴, 사원, 주임, 대리, 과장, 차장, 부장, 임원

      │    │    │      1년 미만(신입), 1-2년차, 3-4년차, 5-7년차, 8-10년차, 11-15년차, 16년 이상
