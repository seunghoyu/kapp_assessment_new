# AI 역량 진단 서비스 — 5레이어 데이터 구조 요약

> **한 줄 요약**  
> 산업·직무·직급·연차·기업규모별로 **3,600개 이상 필터**가 가능한 초개인화 진단을 위해, **5단계 레이어**로 데이터를 나누어 설계한 구조입니다.

---

## 1. 전체 구조 한눈에 보기

| 레이어 | 역할(한 줄) | 핵심 데이터 수 | 누가 이해하면 좋은지 |
|--------|-------------|----------------|----------------------|
| **L1** | **누구를·무엇을** 진단할지 정의 (기준 뼈대) | 25개 데이터셋 | 기획·인사·입찰 담당자 |
| **L2** | **얼마나 잘하는지** 글로벌·실무·규제·생산성 기준 | 15개 | 진단 엔진·문항 설계자 |
| **L3** | **직급·연차**에 따른 위계와 성장 단계 정의 | 17개 | 직급별 문항·피드백 설계 |
| **L4** | **지금 시장**에서의 수요·가격·KPI·트렌드 반영 | 22개 | 실시간 가중치·시장가치 환산 |
| **L5** | **맞춤형 문항 생성** + 적응형 테스트 + 품질 검증 | 7개 | CAT·문항 품질·공정성 |

- **L1~L2**: “누구를, 무엇을, 어떤 기준으로” 측정할지 정함 (정부·글로벌 표준).
- **L3~L4**: “직급/연차/지금 시장” 맥락을 넣어 차별화.
- **L5**: 위 데이터를 조합해 **사용자별 문항 자동 생성** + **품질 보증**.

---

## 2. 레이어 1 — 근간 데이터 (기준 뼈대)

**역할:** “누구를”, “무엇을” 진단할지 **정확히 정의**하는 기초 데이터.

- **분류 체계**: 산업(KSIC), 직업(KSCO), 기업규모, 워크넷 직업정보 → **필터링 기준**.
- **역량 표준**: NCS(문항 생성), Q-Net(난이도 조절), SQF(직급별 가중치) → **측정 기준**.
- **통계·벤치마크**: KOSIS, 기업활동조사, 고용24 임금 등 → **상대적 위치·시장가치 환산**.
- **현장 맥락·규제**: 공공 전문용어, 국가법령, KS 표준 → **법·규제 반영 문항**.
- **시장·조직**: 채용공고, 면접/자소서, 전문가 플랫폼, OHI·일생활균형·KEF 등 → **현실성·조직문화 반영**.

**비유:** 진단의 “자격증” — 정부·공공 데이터 기반이라 **B2B·입찰 시 신뢰도**를 높입니다.

---

## 3. 레이어 2 — 전문성 심화 (얼마나 잘하는가)

**역할:** “해당 업무를 **실제로 얼마나 잘하는지**”를 **글로벌 기준·실무·규제·생산성** 4축으로 측정.

| 축 | 목적 | 대표 데이터 |
|----|------|-------------|
| **글로벌 전문성** | 국제 기준·트렌드 | O*NET, ESCO, Lightcast, LinkedIn, Google Cert |
| **실무 행동** | 전문가가 어떻게 행동하는지 | KPC 역량사전, 중노위 판례, NCS 수행준거 |
| **산업 제약** | 규제 안에서 일하는지 | 5대 산업 컴플라이언스, 광고정책, 금감원 제재 |
| **생산성·성과** | 역량→성과·금액 연결 | HCCP, Forrester TEI, AI 벤치마크, 시장가치 환산 |

**차별화:** 법적 판례 + 산업별 금지표현 DB로 **위험 답안 차단**, Forrester TEI 등으로 **역량의 금전적 가치(시장가치)** 환산.

---

## 4. 레이어 3 — 숙련도·위계 (직급·연차 맥락)

**역할:** **직급·연차**에 따라 “같은 점수도 의미가 다르게” 해석되도록 **맥락**을 부여.

| 축 | 해결하는 질문 | 예시 |
|----|----------------|------|
| **직급 위계** | 스타트업 팀장 vs 대기업 과장 비교 | K-Level 정규화, R&R 표준, SFIA(IT), 글로벌 직급 매핑 |
| **연차별 성장** | 1년차 vs 5년차 기대 수준 | NCS 행동 매트릭스, 성공/실패 GAP, 성장 이정표, 성장 속도 |
| **직급 전환점** | 대리→과장 때 필요한 변화 | 리더십 파이프라인, 직급별 동사 분석, 승진 성공 패턴 |
| **조직 맥락** | 대기업 vs 스타트업 난이도 차이 | 직급별 과업 복잡도, 조직 복잡도 지수, 디지털 워크플로우 위계 |

**비유:** “3년차 대리”에게는 **대리급 문항·기대 수준**으로, “과장”에게는 **과장급 문항·기대 수준**으로 진단합니다.

---

## 5. 레이어 4 — 실시간 시장 지능 (지금 시장 반영)

**역할:** **현재 시장**의 수요·가격·KPI·트렌드를 반영해 역량의 **실시간 가치**를 측정.

| 축 | 활용 예 |
|----|----------|
| **실시간 수요** | 역량별 채용 수요량·긴급도·경쟁률 → 진단 가중치 차등 |
| **시장 가격** | 연봉·사이닝/스톡옵션·고용24·익명 보상 → **시장가치(연봉) 환산** |
| **KPI 연동** | JD·실적발표(DART)에서 목표 KPI 추출 → 실무 기여도 관점 진단 |
| **기업 성장성** | 투자·재무·디지털 성과·직원 증가율 → 고성장 기업 기준 반영 |
| **트렌드·미래** | 역량 생명주기·교육 수요·VC·M&A → **감가상각 경고·학습 방향** 제시 |
| **직급·산업** | 직급별 동사·산업별 KPI 벤치마크 → 동일 역량도 직급·산업별 차등 평가 |

**차별화:** “지금 가장 수요 높은 스킬”에 가산점, **역량의 미래 가치**까지 예측해 학습 로드맵에 반영.

---

## 6. 레이어 5 — 맞춤형 문항 생성 (진단 엔진 완성)

**역할:** L1~L4 데이터를 **조합·재가공**해 **사용자별 맞춤 문항**을 만들고, **적응형 테스트(CAT)** + **품질 검증**까지 담당.

| 축 | 내용 |
|----|------|
| **진단 정확도** | IRT 파라미터·직급별 난이도 매핑 → 사용자 수준에 맞는 문항 자동 선택 |
| **적응형 테스트** | 맞히면 더 어렵게, 틀리면 더 쉽게 → **15~20문항으로 정밀 진단**, 이탈 감소 |
| **문항 변형** | 직급별 동사·R&R·NCS·산업 제약 적용 → 같은 주제를 직급·산업별로 자동 변형 |
| **트렌드 가중치** | 채용 키워드·Lightcast 등 → “지금 수요 높은 스킬” 배점 상향 |
| **E-tray** | 크몽/숨고 워크플로우 → 이메일·메신저 형식 실무 상황 문항 |
| **4중 검증** | ① 중노위 판례(법) ② NCS(국가표준) ③ GPT-4(논리) ④ 베타 테스터(현장감) → **품질·공정성** |
| **편향 보정** | 배경별 정답률 분석 → 업무 능력과 무관한 편향 문항 제거 |

**비유:** “3년차 대리”와 “과장”이 **같은 주제라도 다른 난이도·다른 표현**의 문항을 받고, **최소 문항으로 정확한 수준**을 추정합니다.

---

## 7. 실행 시 주의사항 (공통)

- **이용약관·개인정보**: 사이트 이용약관 검토, **개인정보 완전 제거**.
- **크롤링**: IP 차단 방지(프록시 로테이션), **중복 제거 로직** 필수.
- **품질**: 수집 데이터 **샘플링 검증**, **이상치·노이즈 필터링**.

---

## 8. 정리

| 관점 | 한 줄 정리 |
|------|------------|
| **기획·비개발자** | 5레이어는 “기준 정의(L1) → 전문성 측정(L2) → 직급/연차 맥락(L3) → 시장 반영(L4) → 맞춤 문항·품질(L5)” 순서로, **초개인화 진단**을 가능하게 하는 데이터 설계입니다. |
| **개발자** | L1~L4는 **필터·가중치·벤치마크·트렌드** 입력 소스이고, L5는 이걸 조합한 **문항 생성·CAT·검증 파이프라인**입니다. IRT·4중 검증·편향 보정이 품질을 담당합니다. |
| **차별화** | 정부·공공 기반 **신뢰도** + **실시간 시장 가중치** + **시장가치(연봉) 환산** + **직급/연차 맥락** + **적응형 테스트**로, 단순 문항 나열이 아닌 **데이터 기반 진단 엔진**을 목표로 합니다. |
