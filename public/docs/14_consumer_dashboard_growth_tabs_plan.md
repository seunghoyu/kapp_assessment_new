# 마이 대시보드·나의 성장 탭 기반 UI 기획서

**기준**: kapp_origin 스크롤 형식 → new assessment ERP 대시보드형 전환  
**목표**: 스크롤 최소화, 탭으로 구분하여 한 화면에 가깝게 구성. 기능별 분산 완화, 직관적 그룹핑.

---

## 1. 배경 및 개선 방향

### 1.1 현황 (kapp_origin)

| 구분 | 현재 형태 | 이슈 |
|------|------------|------|
| **KAPP 대시보드** (dashboard-kapp.html) | 세로 스크롤 한 페이지에 8~9개 대형 섹션 | 스크롤이 길어 목적지 찾기 어렵고, ERP 대시보드 느낌과 맞지 않음 |
| **나의 성장** (my-growth.html) | 세로 스크롤 한 페이지에 3개 대형 섹션 | 동일 |

### 1.2 개선 원칙

- **스크롤 지양**: 대시보드에서는 탭 전환으로 화면을 나누고, 탭 내에서도 한 화면(뷰포트)에 맞추는 것을 우선 목표로 한다.
- **탭 구분**: 관리자(admin) 페이지처럼 상단 또는 좌측에 탭을 두고, 탭별로 하나의 “뷰”만 노출한다.
- **기능 그룹핑**: 비슷한 목적·같은 범주 기능은 한 탭으로 묶어, “지금 내가 무엇을 보는지”가 직관적으로 드러나도록 한다.
- **카드·차트 통합**: 여러 카드/차트가 있어도, 같은 맥락(예: 시장 대비 나)이면 한 탭 안에서 섹션/그리드로 배치해 스크롤을 줄인다.

---

## 2. 마이 대시보드 (KAPP 대시보드) 탭 분류

### 2.1 가져올 기능 목록 (origin 기준)

| 순서 | 기능 | 설명 |
|------|------|------|
| 1 | **KAPP 4차원 역량 점수** | 레이더 차트, KAPP 진단 기반 점수, 직급 평균과 비교 |
| 2 | **시장 포지션 분석** | 업계 대비 나의 위치·성장 기회. 카드: 현재 포지션, 경쟁력 분석, 성장 기회 / 레이더: 산업군 벤치마크(상위 10% vs 나) / 상위권 진입 추천 액션 |
| 3 | **커리어 경로 시뮬레이터** | 3~5년 후 경로 예측, 추천 학습 경로 |
| 4 | **시장 벤치마킹** | 동일 업계 대비 나의 위치 (직급 평균·나의 점수·상위 백분율 등) |
| 5 | **AI 분석 인사이트** | 역량 진단 데이터 기반 맞춤형 조언 |
| 6 | **AI 생성 개인 개발 계획 (IDP)** | 진단된 스킬 갭을 메우는 맞춤형 성장 로드맵 |

※ origin에는 그 외 **나의 업무 DNA**, **스킬 성장 추이**, **게이미피케이션·성장 트래킹** 등이 있음. 필요 시 동일 원칙으로 탭/섹션에 배치.

### 2.2 탭 분류 제안

같은 맥락끼리 묶어 **4~5개 탭**으로 나누고, 탭별로 “한 화면”에 가깝게 구성한다.

| 탭명 (가안) | 포함 기능 | 그룹핑 이유 |
|-------------|-----------|--------------|
| **내 역량** | KAPP 4차원 역량 점수 (레이더 + 직급 평균 비교), (선택) 나의 업무 DNA 요약 | “지금 내 역량이 얼마나 되는지” 한눈에 보는 탭. 진단 결과의 핵심 요약. |
| **시장·경쟁력** | 시장 포지션 분석(카드 3종 + 산업군 벤치마크 레이더 + 추천 액션) + **시장 벤치마킹** | “업계/시장 대비 나의 위치”가 동일한 질문이므로 한 탭에 통합. 카드·차트·액션을 한 뷰에 배치해 스크롤 최소화. |
| **성장 로드맵** | 커리어 경로 시뮬레이터 + (선택) 스킬 성장 추이 + **AI 생성 개인 개발 계획(IDP)** | “앞으로 어떻게 성장할지” 경로·시뮬레이션·로드맵을 한 탭에 모음. 학습 경로·IDP를 같은 맥락으로 노출. |
| **AI 인사이트** | AI 분석 인사이트 | “AI가 주는 조언”만 전용 탭. 카드 그리드로 한 화면 구성. |
| **성장 트래킹** (선택) | 게이미피케이션, 배지·포인트·사내 랭킹 | 성장 동기 부여·이력. 필요 시 별도 탭 또는 “나의 성장”과 통합 검토. |

### 2.3 탭별 UI 구성 요약

- **내 역량**: 상단에 레이더 차트(나 vs 직급 평균), 하단 또는 옆에 4차원 점수 카드/바. DNA는 한 블록 카드로 요약 또는 생략.
- **시장·경쟁력**: 상단에 포지션·경쟁력·성장 기회 카드 3열, 그 아래 산업군 벤치마크 레이더 + 시장 벤치마킹(동일 업계) 통계/차트, 맨 아래 추천 액션 리스트. 한 탭 내 2단~3단 그리드로 스크롤 최소화.
- **성장 로드맵**: 커리어 타임라인/시뮬레이터 + 성장 추이(선택) + IDP 블록. 아코디언 또는 카드로 접을 수 있으면 더 좋음.
- **AI 인사이트**: 인사이트 카드만 그리드로 배치.
- **성장 트래킹**: 포인트·배지·리더보드 카드/테이블.

## 3. 나의 성장 탭 분류

### 3.1 가져올 기능 목록 (origin 기준)

| 순서 | 기능 | 설명 |
|------|------|------|
| 1 | **오늘의 1% 효율 챌린지** | 매일 1분 실무 팁, 연속 학습 기록, 완료 수, 주간 목표, 지난 팁 다시보기 |
| 2 | **AI 커리어 멘토링** | 다음 커리어 목표 선택, 1:1 AI 채팅, 현재 vs 목표 역량 갭 분석 |
| 3 | **역량 인증서** | KAPP 역량 인증서 미리보기, 다운로드/공유/링크 복사, 인증서 신뢰성, 뱃지 컬렉션 |

### 3.2 탭 분류 제안 (2안)

**안 A: 3탭 (기능 1:1 대응)**

| 탭명 | 포함 기능 | 비고 |
|------|-----------|------|
| **일일 챌린지** | 오늘의 1% 효율 챌린지 전체 | 오늘의 팁 카드, 적용 완료/나중에 보기, 연속 기록·완료 수·주간 목표, 지난 팁 리스트. 한 화면 우선. |
| **AI 멘토링** | AI 커리어 멘토링 전체 | 목표 선택 → 채팅/갭 분석. 한 탭에서 플로우 유지. |
| **인증·이력** | 역량 인증서 + 뱃지 컬렉션 | 인증서 미리보기, 다운로드/공유, 신뢰성, 뱃지. 한 화면 또는 최소 스크롤. |

**안 B: 2탭 (성장 활동 vs 인증·이력)**

| 탭명 | 포함 기능 | 그룹핑 이유 |
|------|-----------|--------------|
| **성장 활동** | 오늘의 1% 챌린지 + AI 커리어 멘토링 | “매일/지속적으로 하는 성장 활동”으로 묶음. 상단에 챌린지, 하단에 멘토링 진입 카드 또는 인라인 채팅. |
| **인증·이력** | 역량 인증서 + 뱃지 컬렉션 | “증명·이력”이라는 동일 범주. |

- **추천**: 직관성과 메뉴 수를 고려하면 **안 A(3탭)** 를 기본안으로 두고, 실제 구현 시 정보량을 보며 **안 B** 로 단순화할 수 있다.

### 3.3 탭별 UI 구성 요약

- **일일 챌린지**: 오늘의 팁 카드가 메인, 그 아래 연속 기록·완료·주간 목표 카드 3개, “지난 팁 다시보기”는 접이식 리스트 또는 2행 정도로 제한.
- **AI 멘토링**: 커리어 목표 선택 그리드 → 선택 시 채팅 + 갭 분석 블록 노출. 한 탭 내에서 탭 전환 없이 플로우 유지.
- **인증·이력**: 인증서 미리보기 + 액션 버튼(다운로드/공유/링크), 신뢰성 4칸 그리드, 뱃지 컬렉션 그리드.

## 4. 공통 적용 사항

- **탭 전환 시**: 스크롤 위치 초기화, 탭별로 독립된 “한 화면”처럼 동작하도록 구현.
- **반응형**: 작은 화면에서는 탭을 상단 가로 탭 또는 드롭다운으로 제공하고, 카드/그리드는 1열로 줄여도 가독성 유지.
- **접근성**: 탭에 `role="tablist"` 등 ARIA 적용, 키보드로 탭 이동 가능하게 하면 좋음.
- **데이터 연동**: 탭 구분과 무관하게, 기존처럼 진단 결과(localStorage/API)와 연동해 동일 데이터를 각 탭에서 일관되게 사용.

## 5. 정리

| 페이지 | 탭 수 (제안) | 핵심 그룹핑 |
|--------|----------------|--------------|
| **마이 대시보드** | 4~5개 | 내 역량 / 시장·경쟁력(포지션+벤치마킹 통합) / 성장 로드맵(커리어+IDP) / AI 인사이트 / (선택) 성장 트래킹 |
| **나의 성장** | 2~3개 | 일일 챌린지 / AI 멘토링 / 인증·이력 (또는 “성장 활동”+“인증·이력” 2탭) |

origin에서 그대로 가져오되, **스크롤 대신 탭**으로 구분하고, **기능이 직관적으로 묶이도록** 위와 같이 분류하면 ERP 대시보드형으로 개선하기 좋다. 구현 단계에서는 탭별 콘텐츠량을 보고 카드·그리드·아코디언을 조정해 “한 화면” 목표를 맞추면 된다.
