# 방향성 대안

본 문서는 관리자 LMS·스킬 갭·전략 연결·B2B 문의·진행 단계에 대한 방향성 대안을 정리한 것입니다.

---

## 1. 관리자 LMS

**스킬 갭 제공**

- **대시보드 형태** — 부서별 스킬 갭 대시보드
- **스킬 매트릭스 기반 현황 시각화**

---

## 2. 스킬 역량이 낮은 부분 기반 · 스킬 갭 구조적 요인 분석

스킬 갭의 의미: 회사 및 조직이 요구하는 역량 수준에 비해 낮은 경우 갭이 발생함.

- 해당 구조적 요인은 회사마다 다르고, **내부 요인**과 **외부 요인**으로 크게 나뉠 수 있음.
- **AI를 통해서 해당 부분을 선택**하고자 함 (여러 요인들을 리스트업하여 보여주되, 내부 요인과 외부 요인으로 분류).

### 운영 방식

- 대분류 2개(내부 요인 / 외부 요인) 안에서 스킬 갭 요인을 선택하도록 함 (예: 기술 환경 변화, 직무 구조 변화, 세대 변화 등).
- 해당 방식을 **인사 담당자가 선택**할 수 있도록 함.
- **ROI 분석이 같이 이루어져야 함** (스킬링 전략 + ROI 계산). 한계 예산이나 인원 수 등을 입력할 수 있게 해야 함.
- 이후 **AI 분석 작동**.

---

## 3. 스킬 갭 요인이 전략과 연결

저역량의 부서 혹은 개개인의 사람들이, **어떤 교육 설계 전략이 필요하고**, 이 전략이 **어떤 교육과 이어져야 하는지** 제안 (AI를 통한 자동 완성 필요).

**스킬링 전략:** 업스킬링, 리스킬링, 크로스 스킬링

**스킬링 전략 기반 큐레이션 구조**

| 전략 | 교육 목표 | 교육 방식 |
|------|-----------|-----------|
| 업스킬링 | 기존 직무의 역량·성과를 높이기 위한 고도화된 심화형 학습 | 실무 연계 과제, 고급 도구 실습, 동료 피드백 기반 학습 |
| 리스킬링 | 직무 전환을 위한 기초부터 전문성에 이르는 학습 | 온보딩 커리큘럼, 프로젝트 기반 학습, 실습 + 멘토링 혼합 |
| 크로스 스킬링 | 인접 직무·역할 수행을 위한 협업 및 융합형 학습 | 협업 시나리오 기반 워크숍, 유관 부서와 교차 과제 수행 |

**목적:** 스킬 갭 요인이 정의되면, 조직이 해결해야 할 문제가 명확해지고, 인사 담당자가 이를 분석을 통해 확인하면서 솔루션에 대한 신뢰도 및 만족도 상승이 가능할 것으로 보임. (기존의 단순 스킬 갭 제시 → 리포트 생성 → 큐레이션 추천은 정작 매출 증대가 발생하는 큐레이션 단계에서 중단될 것이라고 판단했음)

---

## 4. 교육 방식을 확인 → B2B 기업교육 문의 채널로 이어지기

- **문의사항을 자동 완성**
- **목적:** 큐레이션 단계에서 좀 더 많은 문의가 들어올 수 있게 하기 위함.
- 기존 비즈니스 모델과의 연계.
- 실질적으로 솔루션의 효과를 입증·확인하기 위해서는 어느 정도의 문의가 들어왔는지, 그리고 솔루션 전과 후에 있어서 어느 정도의 **통화 인입률**이나 **영업 담당자의 미팅 빈도**가 늘었는지가 중요할 것으로 판단됨.

### 해당 구조의 차별점

- 단순한 매출 중심의 강의 추천으로 보이지 않음.
- **조직의 문제 구조 → 전략 선택 → 교육 설계**라는 논리적 흐름이 형성됨.
- 온라인 강의 추천 + 문제 정의 요약 + 실행 요청(문의/제안 초안 등)까지 **AI가 함께 생성하는 구조**로 확장 가능 (AI가 해주는 역량 분석이라는 서비스가 좀 더 명확해짐).

---

## 5. 해당 내용으로 진행 시 단계

- **프론트단에서 해당 흐름으로 이어지도록 LMS 개선**
- 단순 확인을 위한 그래프나 쓸데없는 부분들은 제외 (통합 및 간소화가 필요함).
